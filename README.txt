ALTSEASON RADAR — GITHUB PAGES

1. Зайди на https://github.com/new
2. Repository name: altseason-radar
3. Выбери Public
4. Нажми Create repository
5. Нажми uploading an existing file
6. Перетащи ВСЕ файлы из этой папки: index.html, manifest.json, icon-192.png, icon-512.png
7. Нажми Commit changes
8. Открой Settings -> Pages
9. Source: Deploy from a branch
10. Branch: main / root
11. Save
12. Через 1-2 минуты появится ссылка вида:
    https://ТВОЙ-ЛОГИН.github.io/altseason-radar/
13. Открой эту ссылку на iPhone именно в Safari
14. Поделиться -> На экран «Домой» -> Добавить

CoinGlass API-ключ вставляй только внутри приложения во вкладке «Ключи».
