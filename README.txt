Как использовать на iPhone:

1. Распакуй ZIP.
2. Открой файл index_for_copy.txt.
3. Нажми в текст, выбери "Выбрать всё" → "Скопировать".
4. В GitHub открой index.html → Edit.
5. Удали старый код.
6. Вставь скопированный текст.
7. Нажми Commit changes.

Файл index.html тоже внутри, но iPhone часто открывает его как страницу. Поэтому для копирования удобнее index_for_copy.txt.
